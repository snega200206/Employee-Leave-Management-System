# Employee Leave Management System

## DIT Internship 2026 – TASK 07

## 1. Project Overview
The Employee Leave Management System is a web-based application developed to manage employee leave requests, approvals, leave balances, and reports digitally.

## 2. Project Objectives
- Validate leave requests and date ranges.
- Calculate working days and leave balances.
- Manage leave approval and rejection.
- Generate leave request and balance reports.
- Prepare exception reports.

## 3. Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- Pandas
- OpenPyXL
- Visual Studio Code

## 4. Main Modules
- User Login
- Employee Management
- Leave Application
- Leave Approval
- Leave Balance
- Reports and Excel Export

## 5. Project Execution
1. Install the required Python packages.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python app.py
```

5. Open the local URL displayed in the terminal.

## 6. Expected Outputs
- Leave Request Register
- Leave Balance Report
- Exception List
- Test Cases
